# Telegram Kanban Mini App

Полноценная Kanban-система внутри Telegram.

---

## Что реализовано

### Telegram Mini App (React)
- Список проектов — счётчики задач, просрочки, аватарки
- Kanban-доска — drag & drop мышью и пальцем (dnd-kit)
- Карточка задачи — приоритет, дедлайн, цвет, исполнитель
- Подзадачи — чекбоксы, прогресс-бар, предложение закрыть при 100%
- Мои задачи — зоны 🔴🟡🟢, прогресс завершения
- Архив — восстановление и удаление
- Участники — добавление по Telegram ID
- Настройки — название, описание, AI-тон уведомлений
- Поиск по задачам
- Поддержка светлой и тёмной темы Telegram

### Telegram Bot
- `/start` — меню с кнопкой WebApp
- `/my` — мои задачи по зонам + прогресс-бар
- `/new` — создание задачи голосом/текстом
- Диалог с подтверждением и редактированием

### Backend (NestJS)
- REST API — полный CRUD проектов, задач, подзадач, тегов
- JWT авторизация через Telegram initData (HMAC-SHA256)
- Гибкие роли и права внутри проекта
- История изменений задач
- BullMQ очередь уведомлений
- Cron-задачи для отчётов

### Smart Assistant Engine (без внешних API)
- 6 тонов: дружелюбный, минималистичный, деловой, молодёжный, строгий, пасторский
- 8 событий × ~4 варианта = случайные живые сообщения
- Уведомления: назначение, половина срока, -15ч, -2ч, дедлайн, просрочка, завершение

### Task Parser Engine (без внешних API)
- Исполнитель: «Илье», «для Ивана», «назначь Святославу»
- Дедлайн: «завтра», «в пятницу», «через 2 дня», «до 18:00»
- Приоритет: «срочно», «важно», «критично»

### Отчёты
- Еженедельный — каждый вторник 19:00 МСК
- Просрочки — раз в 2 недели при ≥3 просрочках

## Стек

| Слой | Технология |
|------|-----------|
| Frontend | React 18 + TypeScript + Vite |
| Стили | Tailwind CSS + Telegram темы |
| Drag & Drop | dnd-kit |
| Состояние | Zustand |
| Backend | NestJS + TypeScript |
| БД | PostgreSQL + Prisma ORM |
| Очереди | Redis + BullMQ |
| Bot | grammy |
| Инфра | Docker Compose + Nginx + Certbot |

## Запуск

Читай **DEPLOY.md** — пошаговая инструкция от покупки сервера до запуска.

```bash
# Первый запуск
docker compose up -d --build

# Обновление кода
bash deploy.sh

# Логи
docker compose logs -f backend
```
