# Экран «Мои проекты»

На этапе 4 главный список проектов перенесён на дизайн-систему NotoTime. Изменения
касаются композиции и компонентов интерфейса. API проектов, Zustand store,
идентификаторы и маршруты не изменены.

## Сохранённые сценарии

- загрузка всех доступных пользователю проектов;
- открытие Workspace выбранного проекта;
- создание проекта с названием и описанием;
- подключение по коду и отображение результата заявки;
- автоматическое открытие диалога при входе по ссылке с invite-кодом;
- доступ владельца продукта к системной панели;
- отображение участников, количества задач и просрочек.

## Новая композиция

- заголовок и основные действия находятся в верхней рабочей панели;
- проекты выводятся адаптивной сеткой: одна колонка на узком экране, две на
  планшете и три в desktop-оболочке;
- локальный поиск фильтрует уже загруженные проекты по названию и описанию;
- карточка использует устойчивую высоту и отдельную область метаданных;
- пустой список, отсутствие результатов и загрузка имеют разные состояния;
- создание и подключение используют общий компонент `Modal` и стандартные поля.

Цветовой акцент карточки определяется локально по id проекта и не записывается в
данные. Он не влияет на права, содержимое и порядок проектов.

## Проверка

Обязательные сценарии этапа: открыть проект, создать проект, открыть диалог кода,
отфильтровать список, сбросить поиск и проверить экран на 320, 390 и 1440 px.
