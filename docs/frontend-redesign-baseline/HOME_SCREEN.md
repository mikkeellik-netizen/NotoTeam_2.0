# Главный экран NotoTeam

Дата интеграции: 2026-09-21.

## Источник дизайна

Экран собран по спецификации из `nototeam-design-system.zip`: темная оболочка, редакционный hero-блок,
быстрые действия, горизонтальная лента проектов, фильтры задач и постоянная навигация.

## Интеграция с приложением

- `/` открывает новый главный экран.
- `/projects` сохраняет полный существующий список проектов.
- Проекты, участники и счетчики задач берутся из существующего project store.
- Список задач загружается через существующий `tasksApi.getMyTasks`.
- Быстрая задача создается через существующий `tasksApi.create` в первой активной колонке выбранного проекта.
- Быстрое событие открывает существующий календарь через `/my-calendar?create=1`.
- Новый проект открывает существующую форму через `/projects?create=1`.
- Открытие проекта, задачи, календаря и профиля использует существующие маршруты.

## Ограничения текущего этапа

В модели проекта пока нет отдельного поля обложки. Поэтому карточки проектов используют общий локальный
fallback `frontend/src/assets/home-hero.jpg`. Добавлять поле обложки следует отдельной совместимой миграцией,
не смешивая ее с визуальным редизайном.

## Безопасность данных

На этом этапе не менялись схема базы, backend API, идентификаторы сущностей и хранилище файлов. Новый экран
является представлением существующих данных и не создает их копии.

## Проверка

- Mobile: 320 x 700 и 390 x 844, без горизонтального переполнения страницы.
- Desktop: 1440 x 900, постоянная боковая навигация и четырехколоночные быстрые действия.
- Проверены формы быстрого создания проекта, задачи и события без сохранения тестовых записей.
- Проверена консоль браузера: ошибок приложения нет.
